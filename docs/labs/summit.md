# Data & AI Summit：AI エージェントに、どの仕事まで任せるか

AI エージェントは、人より速く答えられます。ただし、使うたびに料金がかかり、答えの正しさも確かめる必要があります。この回では、売上や粗利益の問い合わせを、分析担当の人が答える場合と、AI エージェントが答える場合で比べます。さらに、エージェントの作りを直すと品質・時間・費用がどう変わるかを確かめ、最後に「どの仕事を、どの作りで任せるか」を、参考の月額と一緒に決めます。

この回からの参加も可能です。業務定義と処理記録の読み方は、冒頭で代表例を使って振り返ります。事前イベントへの参加は前提になりません。

## 準備

参加の仕方によって、準備が違います。

| あなたの状況 | 準備 |

| Summit から初めて参加し、事前イベントの内容も操作して確かめたい（任意） | [共通の事前準備](preparation.md)を済ませ、[実習 1](lab1.md)・[実習 2](lab2.md)を自分で進めてから、[開始確認](checkpoint.md)で `開始できます。` と表示されるところまで進める |
| 事前イベントの環境をそのまま使う | 事前イベントで使った Project と教材フォルダを、片付けずに残しておく。主催者から更新の案内があったら、[教材の更新手順](../cloud-shell-workflow.md#教材を更新する)に沿って、教材を Summit 用の版に更新する（事前イベントの版には、開始確認のコマンド `checkpoint start` がありません）。続けて[開始確認](checkpoint.md)で `開始できます。` と表示されることを確かめる（事前イベントの環境なら、作り直さずに始められます） |

準備は、できれば当日より前に済ませてください。当日より前に済ませた方は、当日の最初に[開始確認](checkpoint.md)をもう一度実行します（環境がまだ使えるかを確かめます。1 分ほどで終わり、環境に変更がなければ何も作りません）。当日その場で準備した方は、もう一度実行せずに実習 3 へ進みます。

**新しい Project を使う条件：** 教材の片付けコマンドで Data Agent を削除した Project は、削除から 30 日間は同じ準備ができず、準備や開始確認が止まることがあります。その Project は使わず、新しい Project で共通の事前準備からやり直してください。事前イベントの環境をそのまま使う方は、Summit まで片付けずに残しておきます。

事前イベントで投影した[説明資料（スライド）](https://docs.google.com/presentation/d/1u_TbciboQ0xSoQ0SB4UqgTuiMItl4Iq-Ru2t3Ep4KtA/edit?usp=sharing)も公開しています。事前イベントに参加していない方は、当日の前に目を通しておくと、冒頭の振り返りが分かりやすくなります。

準備が終わらなかった場合も、当日は講師の記録例を使って最後まで進められます（[実習 3 の手順 0](lab3.md#手順-0開始前の確認)）。

## 当日の流れ

全体の目安は 120 分です。進行は当日の講師の案内に従ってください。

| 時間の目安 | 内容 |
|---|---|
| 0–15 分 | [開始確認](checkpoint.md)と、[実習 3](lab3.md)の手順 1（質問の送信を始める）。業務定義と処理記録を例で振り返る |
| 15–35 分 | 手順 2：待つ間に、分析担当の役をやってみる。結果を予測する |
| 35–55 分 | 手順 3〜4：記録を 1 件たどり、全部をまとめて比べる |
| 55–65 分 | 手順 5：AI の回答を、人の目で確かめる |
| 65–95 分 | 手順 6：自分の会社なら、どれを選ぶか |
| 95–120 分 | 共有と、バックアップ・片付けの案内 |

> 当日の開始確認にかかる時間は、まだ確かめている途中です。時間割は、確かめた後に見直します。

## 基本課題で比べること

3 つの質問（決まった集計、カテゴリの比較、次の月の施策についての判断）に、AI エージェントの 2 つのやり方で 1 回ずつ答えさせます（合計 6 回）。2 つのやり方は、Data Agent に分析を **2 回**頼む作り（#2 で見つけた無駄がある作り）と、**1 回**だけ頼んで結果を使い回す作りです。操作は[実習 3 の手順](lab3.md)に沿って進めます。

結果が揃ったら、次の点を読み取ります。

- 人が答える場合と比べて、速さ・費用・正しさはどうか。クエリ集にない質問にはどう答えたか
- 頼む回数を減らすと、品質を保ったまま、費用と時間はどれだけ減るか。半分になったか
- 自動チェックに合格した回答を、人の目で確かめると、そのまま渡せるか
- 人が確かめる時間も入れると、月にいくらかかるか

費用は、使った量に公表価格を掛けた参考の見積もりです。実際の請求額や、本番での削減率を示すものではありません。

## さらに試したい方へ

**3 つの処理経路を比べる：** [3 経路比較の Challenge](routes.md)で、Data Agent に分析を任せる方法、決まった SQL を使う方法、質問に応じて使い分ける方法を比べます。安くても答えられる範囲が狭くなる場合は、その制約も採用条件に含めます。

**同じ条件で繰り返す：** [実習 3 の Challenge](lab3.md#challenge)で、1 回ずつの結果がどれだけぶれるかを確かめます。

どちらも追加の実行と利用料金が発生します。残り時間に合わせて選んでください。

## 最後に残すもの

次の 4 つを、手元のメモか、試算シートの[「採用判断」タブ](https://docs.google.com/spreadsheets/d/1pLNnYmldSzcw6_O6ALXErKiIozIEC0wKE3e22tsYZi0/edit?gid=110606#gid=110606)にまとめます。

1. どの仕事（用途）に使うか
2. どの作りを採用するか（人／毎回取得／再利用）と、その理由
3. 採用しても、人が確かめる必要がある点
4. 参考の月額（AI の料金と、人が確かめる作業を分けて）

決めるのに情報が足りなければ、「今回は判断を保留し、この情報を集める」という結論でも構いません。少ない実行から本番の品質を言い切らず、確かめられた範囲を説明してください。
