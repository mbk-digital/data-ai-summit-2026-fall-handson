# バックアップを残す（環境を後日も使う方）

実習を終えて、後日も同じ環境で続ける方（事前イベントの後に Summit へ続ける方を含む）は、教材フォルダの外にバックアップを残します。Summit では今日の環境をそのまま使います。その間に教材フォルダが消えたり、教材を取得し直したりしても、このファイルを復旧に使えます。復旧時はクラウド環境との一致を確認する必要があるため、講師に相談してください。

```sh
cd ~/summit-workshop && uv run --locked python3 -m workshop.checkpoint backup --file "$HOME/summit-checkpoint-backup.json"
```

**確認：** `バックアップを保存しました：` の後ろに保存先とファイル数が表示されれば完了です。参加者の設定・業務定義・管理台帳が入ります。

> Project やリソースの識別子を含む個人用のファイルです。**GitHub などに公開しないでください。** 同じ名前のファイルがあると上書きしないので、取り直すときは別の名前にします。

バックアップから戻す操作は、講師と一緒に行います。教材フォルダや管理台帳を削除せず、実行したコマンドとエラー文を伝えてください。認証トークンやバックアップファイル自体を公開の問い合わせに添付しないでください。
